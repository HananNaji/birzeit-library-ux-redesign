# Birzeit University Library: Catalogue & E-Resources Redesign

A user-centered redesign of the Birzeit University Library catalogue and
e-resources portal, developed for the Human Computer Interaction course
(COMP322), Second Semester 2025/26.

## Problem
Students struggle to find where to start searching, understand resource
availability, use filters, and access e-resources from off campus. Many fall
back to Google instead of the library system.

## Scope
The redesign focuses on three user journeys:
1. Known-item search and reservation
2. Filtered exploratory search
3. Off-campus e-resource access

## Project Phases
| Phase | Content |
|-------|---------|
| 1. Research | Heuristic evaluation (10 issues), 3 exploratory interviews, 2 personas (Ahmad Khalil, Lina Odeh), scenarios, measurable usability requirements |
| 2. Design | Conceptual model (Search > Evaluate > Access/Reserve), Norman's principles, Nielsen's heuristics, cognitive load and accessibility (WCAG 2.2), wireframes, interactive Figma prototype |
| 3. Evaluation | Usability test with think-aloud (3 participants), task completion, time on task, error count, SUS questionnaire, heuristic re-evaluation, revision plan |

## Key Design Decisions
- Prominent search bar on the homepage with quick filters
- Clear availability labels (Available Online / Available in Library)
- Typo-tolerant search with helpful "no results" suggestions
- Login-required notice and reservation confirmation page
- Dedicated step-by-step off-campus access guide

## Results
- 100% task completion across all three tasks
- Mean SUS score: 77.5 (Good)
- Mean time on task: 65s / 81s / 85s
- Remaining issue: off-campus authentication feedback and onboarding
